# Evaluación de agentes en Databricks

- **Preguntas registradas:** 20 de 20.
- **Idiomas:** inglés y español.
- **Formato:** [visor interactivo](quiz_interactivo.html), una pregunta por pantalla, opciones completas, respuesta correcta marcada, justificación, búsqueda y selector de idioma.

El contenido fue transcrito de las 20 capturas aportadas por el usuario. El visor es el registro canónico, para mantener cada pregunta y sus dos versiones lingüísticas sincronizadas en un único lugar.
