### Pregunta 223: You need to modify an existing product image by replacing a background object while keeping the primary foreground product completely untouched. Which computer vision generation workflow is required?

**Dominio**: Domain 3: Implement computer vision solutions  
**Subdominio**: Subdomain 3.1: Design and implement image- and video-generation solutions  

#### Opciones (EN):
- **A**: Image Inpainting with a binary transparency mask specifying the target replacement region
- **B**: Zero-shot text-to-speech synthesis
- **C**: Training an object detection classifier from scratch

**Respuesta Correcta**: **A**

#### Explicación Oficial (EN):
**Correct Answer: (A) Image Inpainting with a binary transparency mask specifying the target replacement region**

Image inpainting uses an image plus a mask file indicating where the generative model should synthesize new content while preserving unmasked pixels.

• **(A)**: Correct. Image inpainting uses an image plus a mask file indicating where the generative model should synthesize new content while preserving unmasked pixels.
