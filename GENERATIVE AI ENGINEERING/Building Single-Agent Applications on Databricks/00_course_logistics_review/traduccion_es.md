# Revision de la logistica del curso

## Building Single-Agent Applications on Databricks

## Como trabajar con este curso

El curso contiene una serie de lecciones y demostraciones dentro del producto. Estas actividades presentan conceptos importantes y buenas practicas para trabajar con Databricks.

## Databricks Academy Labs

Existe una version del curso que incluye practica mediante una suscripcion a **Databricks Academy Labs**.

La suscripcion proporciona acceso a una biblioteca de cursos populares. Cada uno incluye un ambiente de laboratorio donde se pueden practicar los conceptos mediante ejercicios guiados.

La suscripcion puede adquirirse desde:

- [Databricks Customer Academy](https://customer-academy.databricks.com/learn/signin), para clientes de Databricks y publico general.
- [Databricks Partner Academy](https://partner-academy.databricks.com/learn), para socios de Databricks.
