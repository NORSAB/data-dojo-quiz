## Building Retrieval Agents On Databricks

Congratulations!

You completed the **Building Retrieval Agents on Databricks** course!

By now, you should be able to:

- Explain prompt engineering, context engineering, and RAG concepts for agentic systems.
- Ingest, parse, transform, and chunk unstructured documents for LLM applications.
- Build and optimize embedding, retrieval, and vector search pipelines.
- Track and log retrieval agents using Databricks and MLflow.
- Design and improve knowledge assistant agents using Agent Bricks.
