# Recursos del curso

## Generative AI Application Evaluation and Governance

A continuación se presentan los principales recursos utilizados durante el curso para apoyar el aprendizaje y los ejercicios prácticos.

## Lección: AI System Security

- [Whitepaper: Databricks AI Security Framework (DASF) 2.0](https://www.databricks.com/resources/whitepaper/databricks-ai-security-framework-dasf)

Este documento presenta el marco basado en componentes que permite identificar y mitigar riesgos de seguridad en sistemas de datos e inteligencia artificial.

## Lección: Evaluation Techniques

- [Repositorio: EVAL_GAUNTLET.md — llm-foundry](https://github.com/mosaicml/llm-foundry/blob/main/scripts/eval/local_data/EVAL_GAUNTLET.md)
- [Calibrating the Mosaic Evaluation Gauntlet — Databricks Blog](https://www.databricks.com/blog/calibrating-mosaic-evaluation-gauntlet)
- [Evaluating LLMs/Agents with MLflow — MLflow](https://mlflow.org/docs/latest/genai/eval-monitor/#create-llm-as-judge-evaluation-metrics-category-1)

Estos recursos permiten:

- Examinar los benchmarks y las tareas que componen Mosaic Evaluation Gauntlet.
- Comprender cómo se calibra e interpreta el conjunto de evaluaciones.
- Aprender a crear métricas mediante LLM-as-a-judge y a operacionalizar la evaluación de LLM y agentes con MLflow.

## Orden de estudio sugerido

1. Leer el whitepaper de DASF después de repasar **AI System Security**.
2. Revisar `EVAL_GAUNTLET.md` para relacionar las categorías del benchmark con su implementación.
3. Leer el artículo de Databricks para comprender la calibración del Gauntlet.
4. Consultar la documentación de MLflow al implementar métricas integradas o personalizadas mediante jueces LLM.
