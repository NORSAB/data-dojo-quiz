# Resumen del curso y próximos pasos

## ¡Felicitaciones!

Has completado el curso **Generative AI Application Evaluation and Governance**.

Al finalizar, deberías poder:

- Explicar el significado y la motivación para construir sistemas de evaluación, gobierno y seguridad.
- Explicar las funciones de Databricks Data Intelligence Platform para evaluar y gobernar LLM.
- Describir técnicas de evaluación apropiadas para componentes y tipos específicos de aplicaciones.
- Analizar sistemas de IA completos considerando su rendimiento y costo.

## Síntesis integral

| Área | Ideas principales |
|---|---|
| Motivación de la evaluación | Legalidad de los datos, conducta perjudicial, sesgo, calidad, seguridad y riesgo empresarial |
| Gobierno y seguridad | Unity Catalog, lineage, permisos, auditoría, DASF, filtros de seguridad y Llama Guard |
| Evaluación de LLM | Loss, perplexity, toxicity, métricas por tarea, benchmarks y LLM-as-a-judge |
| Evaluación RAG y del sistema | Context Precision, Context Relevancy, Context Recall, Faithfulness, Answer Relevancy y Answer Correctness |
| Evaluación operativa | Métricas personalizadas, feedback humano, evaluación offline y online, tracing y monitoreo continuo |
| Decisión end-to-end | Equilibrar calidad y valor para el cliente con latencia y costo de infraestructura |

## Próximos pasos recomendados

1. Revisar los recursos del curso.
2. Aplicar las métricas a un dataset representativo del caso de uso.
3. Definir métricas empresariales y operativas personalizadas antes del despliegue.
4. Establecer procesos de revisión humana y monitoreo continuo.
5. Completar el examen del curso.
