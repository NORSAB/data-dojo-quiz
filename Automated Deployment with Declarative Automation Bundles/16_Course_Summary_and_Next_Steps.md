## Course Competencies Achieved
By completing this course, you are now able to:
- **Review** the core principles of DevOps, including continuous integration and continuous deployment (CI/CD) and automated testing, and how they apply to Databricks projects.
- **Evaluate** the tools available for continuous deployment (CD) of Databricks projects, including the Databricks REST API, SDK, and CLI.
- **Explore** the architectural benefits of Declarative Automation Bundles (DABs) for continuous deployment, including standard folder structures and core YAML components.
- **Validate, deploy, and run** Declarative Automation Bundles using the Databricks CLI across multiple target environments using environment-specific variables and configuration overrides.
- **Develop locally** using Visual Studio Code, Databricks Connect V2, and the Databricks VS Code Extension to author, test, and deploy bundles.
- **Automate** deployment pipelines for Databricks projects using GitHub Actions with Declarative Automation Bundles following GitFlow branching best practices.
