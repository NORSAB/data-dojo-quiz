# Deploying and Monitoring Agent Applications on Databricks

- **Preguntas registradas:** 20 de 20.
- **Idiomas:** inglés y español.
- **Formato canónico:** `quiz_interactivo.html`, con una pregunta por pantalla, cuatro opciones completas, clave marcada, justificación, búsqueda y selector de idioma.

El contenido se transcribió de las 20 capturas proporcionadas por el usuario. Las claves se contrastaron con la documentación técnica de Databricks/MLflow para monitoreo, trazas UC, Apps y scorers de producción.

La fuente inglesa literal de cada captura se conserva en `literal_en.js`; el visor la prioriza para mostrar enunciados, bloques de código y las cuatro alternativas sin resumirlos. La versión en español permanece como una traducción separada.
