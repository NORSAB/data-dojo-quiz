# Course Resources

## Resource guide

The course provides four principal technical resources covering AI security, model benchmarking, and automated evaluation.

| Course topic | Resource | Primary use |
|---|---|---|
| AI System Security | [Databricks AI Security Framework (DASF) 2.0 whitepaper](https://www.databricks.com/resources/whitepaper/databricks-ai-security-framework-dasf) | Study the component-based framework for identifying and mitigating security risks across data and AI systems. |
| Evaluation Techniques | [Mosaic Evaluation Gauntlet repository](https://github.com/mosaicml/llm-foundry/blob/main/scripts/eval/local_data/EVAL_GAUNTLET.md) | Inspect the benchmark composition and evaluation tasks used by the Gauntlet. |
| Evaluation Techniques | [Calibrating the Mosaic Evaluation Gauntlet](https://www.databricks.com/blog/calibrating-mosaic-evaluation-gauntlet) | Understand the motivation, calibration, and interpretation of the benchmark suite. |
| Evaluation Techniques | [Evaluating LLMs and agents with MLflow](https://mlflow.org/docs/latest/genai/eval-monitor/#create-llm-as-judge-evaluation-metrics-category-1) | Learn how to define LLM-as-a-judge metrics and operationalize generative AI evaluation. |

## Suggested study order

1. Read the DASF whitepaper after reviewing the AI System Security lesson.
2. Inspect `EVAL_GAUNTLET.md` to connect benchmark categories with their implementation.
3. Read the Databricks Gauntlet article for conceptual and calibration context.
4. Use the MLflow documentation when implementing built-in or custom judge-based metrics.
