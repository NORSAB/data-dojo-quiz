# Course Summary and Next Steps

## Course outcome

The course develops the ability to evaluate, secure, and govern generative AI applications at both component and system levels.

After completing the course, the learner should be able to:

1. Explain why generative AI applications require evaluation, governance, and security systems.
2. Identify Databricks Data Intelligence Platform capabilities that support LLM evaluation and governance.
3. Select evaluation techniques appropriate for different components and application types.
4. Analyze a complete AI system by balancing performance, business value, latency, and cost.

## Integrated course model

| Area | Main ideas |
|---|---|
| Evaluation motivation | Data legality, harmful behavior, bias, quality, security, and business risk |
| Governance and security | Unity Catalog, lineage, permissions, auditing, DASF, safety filters, and Llama Guard |
| LLM evaluation | Loss, perplexity, toxicity, task-specific metrics, benchmarks, and LLM-as-a-judge |
| RAG and system evaluation | Context Precision, Context Relevancy, Context Recall, Faithfulness, Answer Relevancy, and Answer Correctness |
| Operational evaluation | Custom metrics, human feedback, offline and online evaluation, tracing, and continuous monitoring |
| End-to-end decision | Balance system quality and customer value against infrastructure cost and latency |

## Next steps

- Review the course resources.
- Apply the evaluation metrics to a representative dataset from the intended use case.
- Define custom business and operational metrics before production deployment.
- Establish human-review and continuous-monitoring processes.
- Complete the course quiz.
