# Introduction to Evaluating GenAI Applications

## Module context

Patrick introduces the module **The Importance of Evaluating Generative AI Applications on Databricks**.

Evaluation is a critical component of building generative AI applications. Unlike a simple, isolated task, evaluating a GenAI system involves several challenges and requires attention to the different components of the application, the data it uses, user behavior, system responses, governance, and AI risk.

![Learning objectives for evaluating GenAI applications](../assets/images/learning_objectives_evaluating_genai_applications.png)

## Learning objectives

This module aims to:

1. Describe generative AI evaluation systems and their component-specific evaluation needs, including what differs from traditional machine learning.
2. Explain why the legality of the data used in generative AI systems must be considered.
3. Explain why harmful user behavior and harmful system responses must be considered.
4. Explain the difficulties of evaluating generative AI applications, including data governance and AI risks.
5. Describe techniques for addressing data concerns and AI risks, including data licensing and guardrails.

## Areas introduced in this lesson

### Component-specific evaluation

A generative AI application is a system with multiple components. Its evaluation needs must therefore be considered at the level of those individual components as well as at the system level.

### Legal use of data

Evaluation must account for whether the data used by a generative AI system can legally be used for its intended purpose. The module will later connect this concern with data licensing.

### Harmful behavior and responses

The evaluation process must consider both harmful behavior initiated by users and harmful responses produced by the system.

### Data governance and AI risk

Generative AI application evaluation includes difficulties related to the governance of data and the risks introduced by AI behavior.

### Licensing and guardrails

The module will introduce data licensing and guardrails as techniques for addressing data concerns and AI risks.

## Scope note

This introductory lesson defines the module's scope. It names the evaluation concerns and techniques that will be developed in later lessons but does not yet explain their implementation.
