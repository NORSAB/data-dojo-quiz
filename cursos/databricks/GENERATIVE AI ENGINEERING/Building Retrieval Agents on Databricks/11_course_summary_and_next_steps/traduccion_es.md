# Resumen del curso y siguientes pasos

## Building Retrieval Agents on Databricks

Felicitaciones. Has completado el curso **Building Retrieval Agents on Databricks**.

## Competencias adquiridas

Al finalizar el curso, debes ser capaz de:

- Explicar los conceptos de prompt engineering, context engineering y RAG para sistemas de agentes.
- Ingerir, analizar, transformar y dividir documentos no estructurados para aplicaciones con LLM.
- Construir y optimizar pipelines de embeddings, recuperacion y busqueda vectorial.
- Rastrear y registrar agentes de recuperacion mediante Databricks y MLflow.
- Disenar y mejorar Knowledge Assistants mediante Agent Bricks.

## Recorrido completado

El curso cubrio el flujo completo para construir agentes de recuperacion:

1. Fundamentos de retrieval agents y context engineering.
2. Parsing y chunking de documentos.
3. Limpieza y transformacion del texto extraido.
4. Embeddings y Vector Search.
5. Filtros, similarity search y reranking.
6. Desarrollo, tracing y registro de agentes con MLflow.
7. Gobierno de modelos mediante Unity Catalog.
8. Creacion y mejora de Knowledge Assistants con Agent Bricks.
9. Evaluacion y optimizacion mediante feedback de especialistas.

## Siguientes pasos

Para consolidar el aprendizaje en el simulador, conviene practicar especialmente:

- La diferencia entre prompt engineering y context engineering.
- La seleccion de una estrategia de chunking segun el documento.
- El flujo desde documentos hasta embeddings e indices vectoriales.
- La diferencia entre similarity search, filtros y reranking.
- El diagnostico de fallos mediante traces y spans de MLflow.
- La diferencia entre `log_model`, `register_model` y `load_model`.
- El ciclo declarar, desplegar, evaluar y optimizar de Agent Bricks.
- El uso de labeling sessions y guidelines para mejorar respuestas.

## Conceptos clave para el simulador

- RAG combina recuperacion de informacion con generacion mediante un LLM.
- La calidad de un agente depende de la ingestion, parsing, chunking, embeddings y recuperacion.
- Vector Search recupera chunks semanticamente relacionados con una consulta.
- Los filtros reducen el espacio de busqueda y el reranking mejora el orden por relevancia.
- MLflow permite rastrear, empaquetar y registrar agentes.
- Unity Catalog aporta gobierno, permisos, versiones y linaje.
- Agent Bricks ofrece un enfoque declarativo para construir agentes.
- El feedback humano y la evaluacion continua permiten mejorar la calidad del agente.
