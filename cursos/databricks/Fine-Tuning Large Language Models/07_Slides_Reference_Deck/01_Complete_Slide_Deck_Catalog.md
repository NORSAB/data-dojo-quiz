## Technical Highlights from the Slide Deck

### 1. Slide 20: Open-Source Engine Under the Hood
- **`composer`:** Built by MosaicML for distributed PyTorch training. Orchestrates FSDP, DDP, mixed precision, and fault-tolerant cloud checkpointing.
- **`streaming`:** Eliminates local disk bottlenecks by streaming Mosaic Data Shards (`.mds`) directly from cloud storage / Unity Catalog Volumes with sub-second resumption.

### 2. Slide 30: Mosaic Data Shard (MDS) Binary Format
- Binary container format combining `index.json` metadata manifest with compressed binary shards.
- Pre-tokenized samples bypass runtime CPU bottlenecks, feeding GPU tensor cores at 100% hardware saturation.

### 3. Slide 60: DASF Top 5 AI Security Risks
1. **Training Data Poisoning:** Corrupting corpus to skew behavior or inject bias.
2. **Prompt Injection:** Jailbreaking instruction guardrails.
3. **Model Theft / Extraction:** Unauthorized checkpoint replication.
4. **Backdoor ML / Trojaned Models:** Hidden malicious trigger tokens embedded in weights.
5. **Lack of Trustworthiness:** Unmitigated hallucinations and uncalibrated confidence.

### 4. Slide 70: Recommended Learning Rate Sweeps
- Logarithmic exploration grid: $[1\times 10^{-4}, \, 3\times 10^{-5}, \, 1\times 10^{-5}, \, 3\times 10^{-6}, \, 1\times 10^{-6}, \, 3\times 10^{-7}]$.
- LoRA prefers higher learning rates ($3e-5$ to $1e-4$); Full fine-tuning requires lower rates ($1e-6$ to $1e-5$).

### 5. Slides 81–84: LoRA Mathematical Derivation
- Decomposition: $\Delta W = B \times A$, where $B \in \mathbb{R}^{d \times r}$ and $A \in \mathbb{R}^{r \times k}$.
- Slide 83 Calculation: A $100 \times 100$ matrix ($10,000$ params) with rank $r=2$ is reduced to $(100 \times 2) + (2 \times 100) = 400$ params (**96% parameter reduction**).
- Memory footprint drops from $16N$ bytes (full FT) to base weights + tiny adapter tensors, enabling fine-tuning on single GPUs.

### 6. Slide 85: DoRA (Weight-Decomposed Low-Rank Adaptation)
- Decomposes weights into magnitude $m$ and directional matrix $V$: $W = m \frac{W_0 + BA}{\|W_0 + BA\|_c}$.
- Decoupling magnitude from low-rank directional updates bridges the benchmark performance gap with full fine-tuning.
