### Pregunta 9
**Enunciado / Pregunta:**  
What capability does Unity Catalog provide to implement fine-grained access policies on sensitive tables?

**Opciones de Respuesta:**
- [ ] A) Encrypting entire disks only
- [x] **B) Row-level filtering and column-level masking**
- [ ] C) Deleting columns from the physical storage
- [ ] D) Restricting access to only one administrator per account

> **💡 Justificación y Explicación Técnica:**  
> Unity Catalog implementa políticas de seguridad granular a través de **Row-Level Filtering** (filtros a nivel de fila para mostrar solo registros autorizados según el usuario o grupo) y **Column-Level Masking** (enmascaramiento dinámico de datos sensibles en columnas específicas mediante funciones SQL), evitando la duplicación de tablas.  
> **🔗 Referencia Databricks:** *The Data Governance Opportunity & Features - Establishing unified, scalable security frameworks / Unity Catalog Fine-Grained Controls.*
